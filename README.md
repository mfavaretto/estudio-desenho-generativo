# Estúdio Caleidoscópio

Um estúdio de desenho generativo no navegador: desenhe com o mouse (ou o dedo, no celular) e veja o traço se multiplicar em um padrão de caleidoscópio, com rastro colorido e partículas brilhantes.

Feito com HTML5 Canvas e JavaScript puro, sem dependências.

## Como usar

Abra o [index.html](index.html) diretamente no navegador — não é necessário nenhum build ou servidor.

## Controles

- **Espelhos (simetria)** — número de reflexos ao redor do centro
- **Espessura do traço** — largura da linha desenhada
- **Velocidade das cores** — velocidade da transição de matiz (hue)
- **Rastro (permanência)** — quanto tempo o desenho permanece na tela antes de desvanecer
- **Partículas brilhantes** — ativa/desativa partículas que se espalham do traço
- **Espelhar verticalmente também** — adiciona um segundo eixo de reflexão

Use os botões **Limpar tela** e **Salvar imagem** para reiniciar o desenho ou baixá-lo como PNG.
